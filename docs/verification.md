# 验证范围

版本：1.0.1。日期：2026-11-08。作者：Nexus Wang。

## Android 原生实测

设备为 Redmi 22101317C / Android 14。独立 Native 宿主调用插件实际原生实现，使用固定深圳 GCJ02 公开示例坐标，没有申请定位或读取设备 GPS。

| 检查 | 实际观察 |
| --- | --- |
| 地图 | 腾讯底图、标记和加载回调 |
| 算路 | 服务器返回 3 条真实驾车路线；所选约 3,895 米、13 分钟、50 个几何点 |
| 模拟导航 | 转向、车道、路口放大图、模拟车标及剩余里程 |
| 数据就绪 | 算路回包的导航会话 ID 与实际 SDK 就绪事件精确匹配；路线 ID 单独用于选择路线 |
| 回调 | 地图、路线、导航开始、TTS 开始 / 结束和导航停止实际回调 |
| Native 接口协议 | 8 次回调均一次、主线程、code=0；无超时或生命周期中断 |

原生严格协议结果为 `allObservedConditionsPassed=true`。这些结论不替代 UTS 代理或 uvue 真机运行验收。

## 编译与离线验证

- HBuilderX 5.34：Android API、兼容组件注册及完整 uvue 消费者编译；另已完成 Vue2 / Vue3 nvue 消费者编译。
- iOS：真实 SDK、DCloud 运行库及生成消费者在 arm64 iOS 13.4 目标类型检查和链接；没有签名安装或 iPhone 运行验收。
- 离线轨迹：Kotlin 36/36、Swift 38/38。
- 坐标测量：Kotlin 18/18、Swift 23/23。

离线算法测试数量不等于独立 SDK 功能通过数量。
